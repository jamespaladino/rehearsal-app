2. Expected dialogue and cue

Matching is case-, punctuation- and apostrophe-insensitive. Exact requires the cue words contiguously; fuzzy accepts a window of n±1 heard words whose character similarity to the cue is at least the threshold. Both run on partial and final results.

4. Takes and cue annotation

Each take is stored as preprocessed 16 kHz mono PCM, so every engine replays exactly the same samples. Click the waveform (or type a time) to mark where the cue actually ends. Takes live in memory; download the WAV to keep one.

5. Benchmark

Engines run one after another (never at the same time) so they don't compete for CPU. Each take is replayed at real-time speed in chunk-sized pieces; each chunk is delivered when it would have finished arriving from a live microphone, so detection times are directly comparable with the annotated cue end.
